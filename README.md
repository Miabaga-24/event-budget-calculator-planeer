
# Event Budget Calculator

## Overview
This is a beginner-level Python project designed to calculate and monitor the estimated costs of organising an event.

## Features
- Calculates food and transportation costs per participant.
- Calculates the total event cost, including venue expenses.
- Checks whether an event is within or over a specified budget.
- Uses test cases to demonstrate the functions.

## Technologies
- Python 3

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python event_budget_calculator.py
```
